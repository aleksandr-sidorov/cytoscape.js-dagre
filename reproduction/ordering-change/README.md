# Horizontal ordering changes in cytoscape-dagre

[Live demo](https://aleksandr-sidorov.github.io/cytoscape.js-dagre/ordering-reproduction/)

Compares the same graph using 2.5.0, 4.0.1, and 4.0.1 with explicit input sorting.
Input sorting controls insertion order, not final left-to-right placement.

Open `index.html` locally. No installation or build is needed; pinned libraries load from a CDN and require internet access.

This example shows an ordering change, not a guarantee of ascending node order.
